The `circagraph-server` .deb for Debian and Ubuntu (#116). The [Dockerfile](Dockerfile) builds it for one distribution; run it through [`scripts/server-package.mjs`](../../scripts/server-package.mjs) (`debian13` or `ubuntu24.04`), and check a package with `node test/server-deb.mjs`. These files are also the other packages' reference: the [RPM package](../rpm-server/README.md) installs the same services, configuration templates and commands, the [FreeBSD package](../freebsd-server/README.md) adapts the configuration templates, and the platform archive starts the server with `circagraph-server.mjs`. `@PG_MAJOR@` and similar placeholders are filled in when the package is built. `README.Debian` is the administrator's guide the package installs; keep it in step with any change here.

| [`prerm`](prerm)                                                     | Stops (and on removal disables) the services before the package is removed or upgraded.                                                                               |
| [`README.Debian`](README.Debian)                                     | The administrator's guide the package installs: installing, configuring, upgrading, removing and its file layout.                                                     |
