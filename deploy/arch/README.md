The AUR packages for Arch Linux (#331). [`scripts/aur-packages.mjs`](../../scripts/aur-packages.mjs) renders each PKGBUILD for a release's assets, with the files it names beside it, and stable releases push them to aur.archlinux.org (the `aur` job of the [release workflow](../../.github/workflows/release.yml), once the `AUR_SSH_KEY` secret holds an AUR account's private key).

- `circagraph-server` builds cg-convert and pgmp from the release's [platform archive](../platform/README.md), for Arch's PostgreSQL, and lays the server out as the [Debian package](../debian-server/README.md) does, with its services, configuration templates and commands, running on Arch's Node.js (`/usr/lib/circagraph/node/bin/node` links to `/usr/bin/node`). As Arch packages do, installing it sets up nothing: `sudo circagraph-setup` (adapted from the RPM package's) initializes PostgreSQL if it is not yet, and creates the configuration and the database. Upgrades stop the services and say what to review, as the other packages do. [`test/server-arch.mjs`](../../test/server-arch.mjs) builds it with makepkg and installs, sets up, runs, upgrades and removes it in a fresh Arch container, then installs it in place of v0.30.2's `openchronology-server`.
- `openchronology-server` was the server's name until 0.30. `circagraph-server` conflicts with, provides and replaces its versions before 0.31, so installing it removes the old package; `circagraph-setup` then moves `/etc/openchronology` to `/etc/circagraph` (leaving links), keeps that installation's `openchronology` and `openchronology-logs` users, database and state folders (systemd drop-ins from the Debian package's `circagraph-units`), and enables again each service whose old link remains. The old commands' names are links to the new ones, and each service answers to its old name (`Alias=`). Releases also publish a last, empty `openchronology-server` that depends on `circagraph-server` (`--transitional`), so that AUR helpers move installations over, until an AUR merge request folds it into `circagraph-server`.
- `circagraph-desktop-bin` unpacks the release's desktop `.deb`. [`test/desktop-arch.mjs`](../../test/desktop-arch.mjs) builds and installs it, and checks every library it links is found. It was `openchronology-desktop-bin` until 0.30, and conflicts with, provides and replaces its versions before 0.31; like the server's, a last, empty `openchronology-desktop-bin` depends on it (`--transitional`) until the AUR merges the two.
