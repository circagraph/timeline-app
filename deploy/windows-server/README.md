The Circagraph server installer for Windows (#116), `circagraph-server-windows-amd64-setup.exe` (`openchronology-server-windows-amd64-setup.exe` until 0.30). [`build.ps1`](build.ps1) makes it on Windows from the [platform archive](../platform/README.md), bundling its own PostgreSQL 17 with pgmp, och-convert, Node.js and WinSW (for the server, syslog and email services), in an NSIS installer; CI installs, runs, upgrades and removes it (`test/server-windows.mjs`). The installation goes in Program Files, its configuration and database in `%ProgramData%\Circagraph`; installed where OpenChronology Server is, it takes its place, keeping its configuration and database. `README.Windows.txt` is the administrator's guide the installer shows and installs.
