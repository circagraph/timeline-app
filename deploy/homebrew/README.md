The Circagraph server for macOS, as a Homebrew formula (#116). [`scripts/homebrew-formula.mjs`](../../scripts/homebrew-formula.mjs) renders `circagraph-server.rb.in` for a platform archive ([`deploy/platform`](../platform/README.md)), which carries these commands; stable releases push the formula and `tap-README.md` to the circagraph/homebrew-tap repository (with `formula_renames.json`, which moves installations of `openchronology-server`, its name until 0.30), and CI installs it from a local tap (`test/server-homebrew.mjs`). The formula fills in the commands' `@HOMEBREW_PREFIX@`, `@NODE@` and similar placeholders. `README.Homebrew` is the administrator's guide the formula installs.

## Contents

| File                                                                 | What it is for                                                                                                                                                                                     |
| -------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [`cargo-config.toml`](cargo-config.toml)                             | Cargo's configuration in the platform archive, so cg-convert builds offline from its vendored crates.                                                                                              |
| [`cg-import-github`](cg-import-github)                               | The `cg-import-github` command (also `och-import-github`): imports GitHub issues and pull requests into timelines with the GitHub configuration's API key.                                         |
| [`cg-import-logs`](cg-import-logs)                                   | The `cg-import-logs` command (also `och-import-logs`): imports log files into timelines with the syslog configuration's API key.                                                                   |
| [`circagraph-agent`](circagraph-agent)                               | Runs the syslog or GitHub receiver, or email delivery, as your launchd agent (#125): start, stop, restart and status.                                                                              |
| [`circagraph-github`](circagraph-github)                             | Receives GitHub webhooks into timelines until stopped: in a terminal, or as a launchd agent (`circagraph-agent`).                                                                                  |
| [`circagraph-mail`](circagraph-mail)                                 | Delivers account email through Resend until stopped: in a terminal, or as a launchd agent (`circagraph-agent`).                                                                                    |
| [`circagraph-migrate`](circagraph-migrate)                           | Brings the database up to the installed version's schema and restarts the service, and the mail, syslog and GitHub agents, when they run; moves those of `openchronology-server` to the new names. |
| [`circagraph-reset-admin-password`](circagraph-reset-admin-password) | Resets the administrator's password to `ADMIN_INITIAL_PASSWORD` from the configuration (#118).                                                                                                     |
| [`circagraph-server.rb.in`](circagraph-server.rb.in)                 | The formula template: builds cg-convert and pgmp on the Mac and installs the server, its commands (and their names before the rename) and its service.                                             |
| [`circagraph-setup`](circagraph-setup)                               | Finishes an installation: the configuration, PostgreSQL, the database with pgmp, the migration and the service.                                                                                    |
| [`circagraph-syslog`](circagraph-syslog)                             | Receives syslog messages into timelines until stopped: in a terminal, or as a launchd agent (`circagraph-agent`).                                                                                  |
| [`README.Homebrew`](README.Homebrew)                                 | The administrator's guide the formula installs: installing, configuring, upgrading (also from `openchronology-server`) and removing.                                                               |
| [`tap-README.md`](tap-README.md)                                     | The README of the circagraph/homebrew-tap repository, which releases publish beside the formula.                                                                                                   |
